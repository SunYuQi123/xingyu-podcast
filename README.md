# 星屿播客

一个面向 Windows 的非官方小宇宙桌面客户端。用手机小宇宙扫码登录后，可以在电脑上浏览订阅、搜索节目、查看收听历史和播放播客。项目与小宇宙没有官方关联。

> 项目处于早期测试阶段。使用非公开接口可能失效，也可能触发平台风控；请自行了解平台规则。播放进度同步可能出现延迟或冲突，不建议同时在两个设备上播放同一单集。

## 下载与使用

在项目的 Releases 页面下载 Windows x64 安装包 `Xingyu-Setup-*.exe`，运行安装。启动后使用手机小宇宙「发现」页的扫一扫登录。退出登录会删除本机保存的登录凭据。

当前安装包未经数字签名，Windows 可能显示未知发布者或 SmartScreen 提示；请只从项目官方 Releases 下载，并按自己的判断核对文件来源。项目没有自动更新功能。

## 支持的功能

- 读取账号订阅（目前最多显示前 200 个）；搜索播客、浏览单集、查看文字版单集介绍并播放。
- 本地播放队列支持添加、移除和上下调整顺序，当前单集结束后自动播放下一集；队列不会同步到手机。
- 播放器支持 0.75–2 倍速和定时暂停（15、30、45、60 分钟或本集结束）。
- 读取账号的收听历史与播放进度。播放时约每 15 秒、暂停和拖动进度后尝试同步到账号；播放记录同时保存在本机。关闭前请暂停并等待显示“进度已同步”。
- 写入前会检查服务器上是否已有时间更新的记录；这是非原子操作，不能保证并发设备之间不会发生覆盖。

暂不支持在客户端管理订阅、评论或收藏；部分节目、付费单集和特殊音源可能无法播放。网络失败时进度可能只保存在本机，不保证退出后自动补传。小宇宙接口变化可能导致任何功能失效。

## 隐私与安全

客户端直接连接小宇宙相关服务及节目图片、音频所对应的服务器，不经由本项目的自建中转服务器；第三方音频和图片服务器仍会收到连接请求。二维码登录凭据通过 Electron `safeStorage` 使用 Windows 的用户级加密保存在本机应用数据目录；播放器的本地进度存储在 Electron 本地存储。登录凭据不包含在源代码或安装包中。请不要分享二维码、凭据或包含个人信息的日志。

## 从源码运行

需要 Node.js 和 npm，在 Windows PowerShell 中：

```powershell
npm ci
npm start
```

构建 Windows x64 安装包：

```powershell
npm run check
npm run dist
```

产物位于 `dist/`。构建需联网下载 Electron 与安装器依赖。请勿提交 `node_modules/`、`dist/`、本机凭据或个人数据。
